# TaxiPark: учёт автомобилей в таксопарке на WPF и Entity Framework

Этот проект представляет собой настольное приложение для таксопарка. Приложение написано на WPF (C#) и работает с базой данных SQL Server через Entity Framework (Database First). Поддерживаются авторизация с двумя ролями (диспетчер и водитель), учёт автомобилей и водителей с несколькими категориями прав, оформление смен с проверкой категории и подсчётом пробега, отметки о техобслуживании и просмотр комментариев водителей.

## Установка

1. Клонируйте репозиторий:

```bash
   git clone https://github.com/m4tvey7/TaxiPark.git
   cd TaxiPark
   ```

2. Создайте базу данных `TaxiPark`: откройте файл `database/taxipark.sql` в SQL Server Management Studio и выполните его целиком (F5). Скрипт создаёт базу, таблицы и тестовые данные. Если база с таким именем уже есть, она будет пересоздана.
3. Откройте решение `TaxiPark.sln` в Visual Studio 2019 или новее (нужна рабочая нагрузка «Разработка классических приложений .NET» и .NET Framework 4.7.2) и проверьте строку подключения `TaxiParkEntities` в файле `TaxiPark/App.config`: значение `data source` должно совпадать с именем вашего SQL Server.
4. Восстановите NuGet-пакеты (Entity Framework) и запустите проект клавишей `F5`.

## Использование

### Вход в систему

При запуске открывается окно входа. Введите логин и пароль. Роль определяется автоматически: сначала логин ищется среди диспетчеров, затем среди водителей. Самостоятельной регистрации нет: водителей добавляет диспетчер.

|Роль|Логин|Пароль|
|-|-|-|
|Диспетчер|`sokolov`|`sokolov123`|
|Водитель (категория B)|`petrov\_ai`|`petrov123`|
|Водитель (категории B и D1)|`fedorov\_me`|`fedorov123`|
|Водитель (смена уже открыта)|`ivanov\_sn`|`ivanov123`|

Остальные пароли строятся так же: логин до символа «\_» и `123`.

### Работа водителя

Выберите в списке свободный автомобиль и нажмите «Начать смену». Приложение проверит, что у вас есть категория прав, которую требует автомобиль, создаст путевой лист и пометит автомобиль занятым. По окончании смены введите конечные показания спидометра, при необходимости напишите комментарий о состоянии автомобиля и нажмите «Завершить смену». На вкладке «Мои смены» хранится история смен.

**Ожидаемый результат:**

```
Смена завершена. Пробег за смену: 165 км.
```

### Работа диспетчера

Вкладка «Автомобили»: поиск по марке, модели и госномеру, кнопки «Добавить», «Изменить», «Удалить», «Отправить на ТО» и «ТО пройдено» (с описанием работ и стоимостью). Вкладка «Водители»: добавление, изменение и удаление водителей, категории прав отмечаются флажками. Вкладка «Смены и комментарии» показывает все смены с пробегом; флажок оставляет только смены с комментариями водителей. Автомобиль, который сейчас в смене, удалить нельзя.

## Структура проекта

* `TaxiPark.sln`: решение Visual Studio.
* `TaxiPark/App.xaml`, `TaxiPark/App.xaml.cs`: общий контекст БД, текущий пользователь (`CurrentDispatcher`, `CurrentDriver`), номера статусов автомобилей, стили приложения.
* `TaxiPark/LoginWindow`: окно входа.
* `TaxiPark/DispatcherWindow`: окно диспетчера (четыре вкладки).
* `TaxiPark/DriverWindow`: окно водителя.
* `TaxiPark/CarEditWindow`: форма добавления и изменения автомобиля.
* `TaxiPark/DriverEditWindow`: форма добавления и изменения водителя.
* `TaxiPark/MaintenanceWindow`: отметка о техобслуживании.
* `TaxiPark/Entities/`: модель Entity Framework (EDMX) и классы таблиц.
* `database/`: SQL-скрипт создания базы данных `taxipark.sql`.
* `docs/screenshots/`: скриншоты для отчёта и README.

## Данные

Используется база данных `TaxiPark` (SQL Server), разработанная в лабораторной работе № 3. Основные таблицы:

* `Dispatcher`: диспетчеры (ФИО, логин, пароль).
* `Driver`: водители (ФИО, телефон, стаж, логин, пароль, дата приёма).
* `LicenseCategory` и `DriverCategory`: справочник категорий прав и связь «водитель — категории».
* `CarBrand`, `CarModel` и `CarStatus`: справочники марок, моделей и статусов автомобилей.
* `Car`: автомобили (модель, год, госномер, цвет, пробег, требуемая категория, статус).
* `Waybill`: путевые листы (смены) с показаниями спидометра и комментарием водителя.
* `Maintenance`: записи о техобслуживании (дата, пробег, описание работ, стоимость).
